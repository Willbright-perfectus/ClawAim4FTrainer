# ClawAim4FTrainer

The original Android trainer is preserved in `ClawAim4FTrainer-source.zip`.

## ClawLab 3D mobile trainer

The new [ClawLab project](ClawLab/README.md) adds a full 3D training range, configurable gun behavior and movement, ten drills, editable four-finger controls, profile import/export and automated tests.

Start with [ClawLab’s installation guide](ClawLab/README.md), [calibration instructions](ClawLab/docs/CALIBRATION.md) and [research/fidelity notes](ClawLab/docs/RESEARCH.md). Android APKs are generated by the **ClawLab Android** workflow. This is a playable preview pending physical-device performance and calibration checks.
